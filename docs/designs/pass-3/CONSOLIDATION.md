# Consolidation plan

1. Problem -> fix -> job is ONE flow. Notifications = single Issue screen (list left, detail right; phone detail = Approval). Detail action bar: Approve / Snooze / Deny (or "Mark resolved" when no fix). After approval, embed the shared job-progress block (States #7). Jobs = filtered list of the same job object using that block. Main "Needs attention" = widget showing top 3 open issues; rows open the issue, no inline action buttons; one "All notifications" link. Topology banners keep one "Review fix" link into the Issue. Status words: shared StatusBadge set.
2. HomeControl, DashboardEdit, Kiosk = one dashboard renderer in modes view / edit / display, same widgets and data. HomeControl: delete bottom tab bar; standard phone header. DashboardEdit: collapsed shared rail (64px) instead of a custom rail; header Name · Saved · Undo · Share · Done; delete "Editing" chip; settings panel = WHO CAN SEE / WHO CAN CONTROL. Kiosk: same widget components at display density; keep device sign-in variant.
3. Topology + TopologyGraph = one responsive screen. Only switch: Tree/Graph (+ one "Expected-down" toggle). Phone inspector = bottom sheet with the same sections as desktop panel (RUNS ON / CONNECTIONS / MOUNTS). Same facts and counts on both. Desktop: drop zoom readout/extra chips; footer actions: Open + overflow (Restart, Logs); Repair only in the panel, not also on the edge label.
4. One Inventory list (Workloads retitled): kind filter System / VM / LXC / Container / Service, Group by; rows have overflow menu only; bulk bar Restart, Stop + overflow (Back up, Migrate). One Detail template for service and system: header (name, status, subtitle, primary action + overflow), tabs; Overview is summary only. ServiceDetail: drop duplicated update badge; Open primary, Restart/Update/Backup now in overflow. SystemDetail tabs: Overview, Guests, Storage, Updates, Certificates, Settings; Guests = Inventory filtered by host; delete capability tag chips; capabilities as one compact spec line on Overview; no channel toggle (link to update policy).
5. Search absorbs Request: media filter variant with IN YOUR LIBRARY / AVAILABLE TO REQUEST groups and Request actions. Chips: All + 3 relevant + More, grant-filtered. "My requests" is a saved filter, not a header button.
6. Plugins tabs: Installed (incl. pending updates with Approve), Discover, Sources. Delete right-hand Sources panel. UpdatePolicy = sub-view from Installed ("Update policy…"): only grid + cell editor, no pending list. PluginInstall Updates row shows inherited policy with a link to the policy view. Signed badge only when Unsigned.
7. People tabs: People, Groups. Group detail = GrantEditor. Delete People's side GROUPS panel. Invite sheet: group picker + VPN toggle only (expiry lives on grants in GrantEditor). GrantEditor: move RECENT CHANGES behind an "Activity" link.
8. One credential row (username, masked password, Copy, Rotate) + one step-up sheet (States 8a/8b). MyApps uses the row and invokes the shared sheet; delete its inline step field and helper text. SecretReveal = the row's revealed state.
9. Shared chrome (see job prompt). Desktop 1280x860, phone 390x844.
10. Backups tabs: Coverage (default; verify status folded into rows), Schedules, Destinations; restore/migrate wizard stays a sheet. ServiceDetail Backups tab shows this service's coverage row only.
11. Busyness: Main drops landing filter chips; Notifications drops per-row approve buttons and category chips; Plugins shows signature badge only when unsigned; StatusBadge labels limited to Healthy, Warning, Failed, Info, Idle, Planned.
12. FirstRun and CreateService share one stepper component.
